# Demo Showcase Project

Projeto funcional inicial que demonstra o funcionamento do estúdio.

## Composições
1. `demo-showcase-reel` (1080x1920, 9:16, 30fps) - Formato Reels/TikTok
2. `demo-showcase-landscape` (1920x1080, 16:9, 30fps) - Formato YouTube/Horizontal

## Recursos Utilizados
- Tailwind CSS v4 para estilos utilitários
- Física de animação `motionSpring` (presets `snappy` e `bouncy`)
- Tipografia cinética (`KineticText`)
- Fundo procedural com glow e grid (`BackgroundGrid`)
- Barra de progresso sincronizada (`ProgressBar`)
