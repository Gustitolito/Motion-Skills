# Motion Skill Routing

Abra esta referência quando a descrição das skills não for suficiente para escolher a família de motion.

| Necessidade dominante | Skill principal | Apoios frequentes | Evite quando |
| --- | --- | --- | --- |
| Refinado, premium, controlado | `studio-smooth-premium` | institutional, brand/logo, post | a intenção pede exagero/cartoon |
| Institucional/editorial/documental | `studio-institutional-editorial` | smooth, data-viz, post | hype/agressividade é o herói |
| Promo rápido/lançamento | `studio-fast-promo` | expressive, kinetic, audio | leitura longa e sobriedade dominam |
| Impacto/cartoon/overshoot | `studio-expressive-impact` | fast-promo, particles, audio | premium contido/institucional |
| Collage/cutout/stepped | `studio-stop-motion-collage` | paper/fabric, post | suavidade contínua é requisito |
| Papel/tecido/tátil | `studio-paper-fabric-texture` | collage, depth, post | materialidade não tem função |
| Orgânico/líquido/macio | `studio-organic-liquid-soft` | smooth, post, audio | simulação física fotorealista |
| Títulos/teaser dramático | `studio-cinematic-titles` | depth, post, audio | lower-third ou informação utilitária |
| Texto como protagonista | `studio-kinetic-typography` | timing, fast/social | texto é apenas legenda passiva |
| Gráficos/dados/explainer | `studio-data-viz-explainer` | timing, kinetic, social | gráfico é meramente decorativo |
| YouTube/Reels/social narrativo | `studio-youtube-social` | kinetic, data-viz, audio | filme de marca sem lógica de retenção |
| Logo/identidade/UI | `studio-brand-logo-ui` | smooth ou expressive | peça não precisa de sistema de marca |
| Câmera/parallax/2.5D | `studio-depth-camera-2p5d` | cinematic, smooth | transição plana simples resolve |
| Partículas/bursts/confete | `studio-particles-bursts` | expressive, fast | seriam apenas preenchimento |
| Acabamento/color/glow/grain | `studio-post-finishing` | qualquer família | usado para esconder motion fraco |

## Regras de composição

- Combine no máximo duas linguagens dominantes; técnicas são apoio.
- Prefira a solução mais simples que preserve a intenção.
- Skills de formato (social, data-viz, brand) podem coexistir com uma linguagem (smooth, fast, collage etc.).
- Skills técnicas (depth, particles, post, audio) não devem definir sozinhas a direção da peça.
- `studio-qa-art-direction` entra no fim para validar, não para escolher o conceito.
